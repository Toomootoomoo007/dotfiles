# 日記作成・AI分析コマンド

以下の手順で今日の日記を管理してください。

```
VAULT_PATH="/Users/aokitomohiro/Documents/Obsidian Vault"
TODAY_ISO=$(date '+%Y-%m-%d')
TODAY_LABEL=$(LC_TIME=ja_JP.UTF-8 date '+%Y年%m月%d日(%a)')
FILE="$VAULT_PATH/00_INBOX/$TODAY_LABEL.md"
TEMPLATE="$VAULT_PATH/templates/日記テンプレート.md"
```

## ステップ1: ファイル確認

ファイル `00_INBOX/$TODAY_LABEL.md` が存在するか確認する。

---

## ステップ2A: ファイルが存在しない場合 → 新規作成

`templates/日記テンプレート.md` を読み込み、以下の置換をしてファイルを作成する：

- `YYYY-MM-DD` → TODAY_ISO の値（例: `2026-05-28`）
- frontmatter の `description` は空文字列のまま残す
- ファイル名は `$TODAY_LABEL.md`（例: `2026年05月28日(木).md`）
- 保存先: `00_INBOX/`

作成後、「日記ファイルを作成しました: `00_INBOX/$TODAY_LABEL.md`」と伝える。

---

## ステップ2B: ファイルが存在する場合 → AI分析

1. `## 🤖 AI分析` セクションがすでに存在する場合は「本日の日記は分析済みです」と伝えて終了する。

2. `## 📝 今日の日記` セクションに内容がない（`-` のみ）場合は「日記の内容がまだありません」と伝えて終了する。

3. 内容がある場合、以下を行う：

   a. frontmatter の `description` フィールドを日記の内容から一文（50字以内）で埋める。形式：「今日の一言。何があり何を感じたか」。

   b. ファイルの末尾に以下のセクションを追記する：

```markdown

---

## 🤖 AI分析

**感情サマリー**
（今日の感情・気分を2〜3文で要約）

**今日の学び**
（気づき・発見・学んだことを箇条書きで）

**明日やること（最大3つ）**
- 
- 
- 

**AIからの気づき**
（日記から読み取れるパターンや視点を一言）
```

分析は300字以内。批判せず、日記に書かれていないことを推測・創作しない。
